Put your photos here!

Name them anything you like — just make sure the filenames match what's
listed in lib/data.ts under `photos`. For example, if you add a photo
called "us-01.jpg" to this folder, set its `src` to "/images/us-01.jpg".

Until you add real photos, each polaroid will show a cute placeholder
instead of a broken image, so the site still looks complete.
